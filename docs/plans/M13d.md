### D-174 · Mimari şema Mermaid ile README'de
- **Karar:** GitHub'ın doğrudan çizdiği Mermaid `flowchart`: Tarayıcı (HTMX + Alpine, Tailwind) ve Chrome eklentisi (Bearer token, `/api/ext`) → FastAPI (middleware: TrustedHost, SecurityHeaders, Session, CSRF) → routers → services → SQLModel → PostgreSQL / SQLite; yanlarda WeasyPrint (PDF), APScheduler (hatırlatmalar), e-posta (console/SMTP), Alembic; kişisel ortam Docker Compose.
