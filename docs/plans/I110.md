# I110 — UI consistency: one Add-button pattern and the select chevron

Issue #110. Branch `ui-add-pattern`. No migration, no new dependency.
Fatih'in ekran görüntülerinden (2026-11-26): select oku kenara çok yakın; "New CV" `+` ikonsuz ve diğer ekleme butonlarından farklı yerde; "Add / New / Create" karışık. Fatih "tek bir pattern" istedi ve kararları Claude'a bıraktı ("Claude karar verdi").

## Kararlar (DECISIONS)

### D-196 · Tek ekleme deseni
- **Kelime:** her ekleme/oluşturma butonu "Add {şey}": Add job, Add goal, Add CV, Add cover letter, Add task, Add note, Add question, Add story, Add bullet, Add {bölüm adı}. "New …" ve "Create …" ekleme butonunda kullanılmaz. Modalın başlığı ve gönder butonu da aynı kelimeler ("Add goal" modalı → "Add goal" butonu). İstisna: "Create account" (giriş ekranı, bir listeye ekleme değil). Form etiketleri ("New password") buton değildir, değişmez.
- **İkon:** hep `icon("plus")`, metnin solunda. Düz "+" karakteri kullanılmaz.
- **Üç seviye, yeri ve görünüşü sabit:**
  1. **Sayfa:** `page_header`'ın sağında, primary (mor) `h-10 px-4`. Applications (Add job), Learning (Add goal), Documents (Add CV / Add cover letter, sekmeye göre).
  2. **Kart / bölüm:** kart başlık satırının **sağında** (başlık solda, `justify-between`), secondary (çerçeveli) `h-8 px-3 text-[13px]`. Plan kartı (Add task), Goals kartı (Add goal; alttan başlığa taşınır), Profil bölümleri (Add education …; sadece ikonlu kare buton yerine etiketli).
  3. **Satır / metin içi:** link stili (`text-link`, küçük, kalın) + ikon. Hedef satırındaki Add task, Next reminder kartı, Add bullet, boş durum linkleri ("Add a master CV").
  - Bir alanın yanındaki **gönder butonu** (timeline notu, mülakat soruları, hikâye bağlama): secondary `h-9` + ikon, "Add note" / "Add question" / "Add story".
- **Kod:** `components/forms.html`'e `add_classes(level)` makrosu (page / card / inline / submit sınıfları). Butonların kendi nitelikleri (data-dialog-open, hx-get, type=submit) şablonda kalır; sadece sınıf ve ikon ortak. Profilin `icon_button("plus", …)` çağrısı kalkar; `icon_button` kalem için kalır.
- **Alternatifler:** "New" her yerde (SPEC ve testlerde "Add job" çok yerde; listeye eklemede "New note" garip); seviyesiz tek buton (kart içinde mor buton sayfanın ana eylemiyle yarışır).

### D-197 · Select oku
- Tarayıcı oku kapatılır (`appearance: none`), yerine SVG chevron arka plan resmi: sağdan 12px, 16px; `padding-right: 36px`. Renk her iki temada okunan orta gri (`#8A94A6`), tema değişkeni eklenmez (`test_static` prototip değişkenlerini birebir kontrol ediyor). `input.css`'te tek kural, bütün select'ler.
- **Alternatifler:** sarmalayıcı span + ikon (10 şablon değişir); sadece padding (tarayıcı oku yine kenara yapışık kalır).
