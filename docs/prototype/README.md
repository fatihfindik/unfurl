# Prototype

Clickable prototype of Unfurl, used as the design reference for layout, copy and interactions.

- Live version (owner only): https://claude.ai/artifact/9kthYWStmiLvG6aY27KZ1Y
- These `*.dc.html` files are the source of each screen. They need the design canvas runtime to render, so read them as markup and reference, not as production code.
- `canvas.json` lists the screens and their order.

Version 3 (2026-11-10). Main menu: Applications (home), Learning, Documents, Settings. The assistant is a floating panel on every page; My profile opens from the avatar menu.

Screens: Login, Onboarding, Applications, ApplicationDetail (Apply in 3 steps: Should I apply? → Prepare documents → Final check; Job & details tab; timeline panel), Documents, CVEditor, CoverLetters, Learning, Profile, Settings, Extension (Chrome popup).

Version 1 screens are kept in `_archive_v1/` for reference.

All companies and the person (Jana Novak) are sample data.
